# Actual IT Website

Boutique IT support, consultancy and custom software for Brisbane businesses.

**Live:** https://actualit.com.au

## Tech
- Static site hosted on **Cloudflare Pages**
- Auto-deploys on push to `main`
- CSS custom properties + modern CSS (grid, clamp), no build step

## Deploy
Pushing to `main` triggers a Cloudflare Pages build automatically.
